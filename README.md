# Flappy C

App web instalável do Flappy, com moedas, skins, conquistas e desafio diário.

## Jogar

Abra `index.html` em um servidor local, ou use o site publicado no GitHub Pages.

No celular ou no Chrome/Edge do computador, use **Instalar app** para colocar na tela inicial.

## Controles

- **Toque / clique / Espaço**: voar
- **Esc**: pausar ou voltar
- **F11**: tela cheia
- **M**: mudo

O progresso fica salvo no navegador.
